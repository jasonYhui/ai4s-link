# 学术招聘

面向 AI4S（AI for Science）交叉学科的招聘信息聚合：高校教职、博士后、科研助理、实验室工程师、硕博招生。

## 当前状态

**还没有收录任何职位。** 这个页面刚建，内容从零开始。

## 为什么先建一个空页

导航里留位置，比藏在角落强——有人想投招聘信息时，知道该往哪儿放。

## 怎么投稿

- **GitHub Issue**（推荐，适合已经发布在官网的正式招聘）：[提交招聘信息](https://github.com/jasonYhui/ai4s-link/issues/new)
- **交叉论坛**（适合内推、口头岗位、先聊聊看的机会）：[发到 GitHub Discussions](https://github.com/jasonYhui/ai4s-link/discussions/new?category=q-a)

请在标题里带上 `[招聘]` 前缀，方便检索。

## 收录标准

一条招聘信息要进这个页面，需要满足：

1. **方向相关**——AI 与交叉学科结合（生命科学、材料、地球科学、化学、医学、工程等）
2. **信息完整**——单位、岗位、研究方向、要求、待遇区间、投递方式、截止时间
3. **有官方出处**——学校人事处、实验室主页或招聘系统的可验证链接
4. **不收费**——付费内推、培训机构、收费中介一律不收

信息不全的「高薪急招」不收。这一条和资源库同一个标准：**宁可空着，也不放不可信的东西。**
