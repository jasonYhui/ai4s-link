# CARSI 资源要不要单独申请？

**不用。** 这是最常见的误解。

CARSI 的机制是「统一身份认证」，不是「报名申请」。你学校的校园网账号本身就是通行证。

## 正确的步骤

1. 打开目标服务的登录页，选择 CARSI 认证
2. 选择你所在的高校
3. 跳转到学校的统一身份认证页，用学号 / 工号登录
4. 通过后自动回到目标服务，直接可用

以国家超算互联网为例：<https://www.scnet.cn/ui/mall/> 登录时选 CARSI 即可，**无需学校申请开通，也无需重复注册账号**。

## 三个常见误解

| 误解 | 实际 |
|---|---|
| 要先找学校超算中心申请配额 | 不用，CARSI 认证后直接进平台按需申请 |
| 要单独注册一个账号 | 不用，用的就是校园网身份 |
| 必须坐在校园网 IP 里 | 联邦认证认的是身份不是 IP；但个别服务另有 IP 限制，看它的具体说明 |

## 前提条件

- 你的学校是 CARSI 会员单位（已接入 1033 所高校，覆盖全部 985 / 211 / 双一流）
- 你持有有效的校园网账号

学校是否接入，可在 <https://www.carsi.edu.cn> 的「学校&机构（IdP）」里查。
