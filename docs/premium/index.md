<h1 id="premium-title">精选资源</h1>

<p class="premium-lede">这里放<strong>需要付费</strong>的资料：课程、数据集、工具订阅、书籍。<br>
免费资源在 <a href="/resources/">科研资源</a>，两边严格分开。</p>

<div class="premium-notice">
  <strong>为什么单独分开？</strong>
  <p>科研资源库承诺「一条付费都不收」，这是它的价值所在。付费内容放在这里，既不污染免费库，也不用藏着掖着。</p>
</div>

<h2>当前状态</h2>

<p>还没有收录任何付费资源。这个页面刚建，内容从零开始。</p>

<h2>收录什么</h2>

<ul>
  <li><strong>课程</strong>——能补齐某个方法缺口的系统课（如因果推断、单细胞分析）</li>
  <li><strong>数据集</strong>——需要申请或付费才能拿到的领域数据</li>
  <li><strong>工具订阅</strong>——有免费替代品但付费版明显更好用的（会写清区别）</li>
  <li><strong>书籍</strong>——方法和工具书，不是什么书都推</li>
</ul>

<h2>收录标准</h2>

<p>一条付费资源要进这个库，必须同时满足：</p>

<ol>
  <li><strong>价格公开</strong>——写清多少钱、什么计费方式，不许「详询」</li>
  <li><strong>有官方出处</strong>——官网页面优先，不接受道听途说</li>
  <li><strong>说清适用人群</strong>——谁适合用、谁不需要买</li>
  <li><strong>和免费方案比过</strong>——必须写明「免费替代品是什么，差在哪」</li>
  <li><strong>标验证日期</strong>——价格会变，日期就是信息新鲜度的凭据</li>
</ol>

<p class="premium-foot"><strong>不写「值不值」的软文。</strong>只摆事实：多少钱、能干什么、免费方案差在哪。买不买自己判断。</p>
