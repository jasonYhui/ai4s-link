# 模型

面向科研场景的模型清单：哪些能用、免费额度多少、上下文能装多长、接口是否兼容 OpenAI、适合干什么活。

和资源库的分工：**资源库**收的是「能白嫖的服务」，这里只收**模型本身**——同一个平台下的多个模型在这里逐条列，方便按上下文长度、模态、价格横向比较。

## 当前状态

首批收录 1 条（智谱 GLM 的两个免费模型），其余在陆续核实中。

## 条目格式

每条模型按同一套字段写，缺一项就不收：

| 字段 | 说明 |
| --- | --- |
| 名称 | 官方模型名，可直接填进请求体的那种（如 `glm-4.7-flash`） |
| 提供方 | 公司 / 实验室 |
| 免费额度 | 免费到什么程度：全免费、限次、送额度、还是按量计费 |
| 上下文 | 能塞进多少 token，决定能不能整篇论文喂进去 |
| 接口 | 是否兼容 OpenAI 格式、有无 SDK |
| 适合场景 | 一句话说清它擅长什么 |
| 限制 | 并发、频率、地区、token 上限等已知约束 |
| 验证日期 | 最后一次确认信息无误的时间 |

## 已收录

### 智谱 GLM-4.7-Flash / GLM-4.6V-Flash

- **名称**：`glm-4.7-flash`（文本）、`glm-4.6v-flash`（视觉）
- **提供方**：智谱 AI 开放平台
- **免费额度**：官方定价页写明输入、输出、缓存**全免费**
- **上下文**：200K（能整篇论文塞进去读）
- **接口**：OpenAI 兼容格式，改个模型名就能跑
- **适合场景**：批量读论文摘要、抽结构化信息；`4.6v-flash` 可用于图表与截图理解
- **限制**：官方未标 token 上限，实际仍有并发与频率限制；上下文塞太长会变慢
- **验证日期**：2026-11-23
- **官方链接**：[open.bigmodel.cn/pricing](https://open.bigmodel.cn/pricing)
- **详细用法**：[资源库条目](/resources/zhipu-free-models)

## 收录标准

1. **科研可用**——至少能用于读文献、写代码、算数据、处理图表中的一类
2. **信息可核**——额度与上下文以官方定价页 / 文档为准，不写「据说免费」
3. **写明限制**——并发、频率、地区、token 上限，有一条写一条
4. **不吹性能**——不放跑分截图，只写适用场景；benchmark 容易过期
