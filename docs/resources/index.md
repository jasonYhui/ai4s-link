## 收录标准

一条资源能进这个库，要同时满足四条：

1. **免费**——不是试用、不是优惠券、不是「首年免费」。要付费才能用的，一律不收
2. **有出处**——官方页面、官方公告优先。官方没公开的数值必须标明是社区口径
3. **写清限制**——免费额度、限流、前置条件（要不要实名、要不要绑账号）
4. **标验证日期**——政策会变，日期就是信息新鲜度的凭据

**宁可只有几条，也不要几十条里混着付费和错误。**
