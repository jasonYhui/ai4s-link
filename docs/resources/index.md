## 收录标准

一条资源能进这个库，要同时满足四条：

1. **完全免费**——能长期免费用，不是试用、不是优惠券、不是「首年免费」。要付费才能用的，一律不收
2. **有官方出处**——能指到官网页面或官方公告，不是二手转述
3. **写清限制**——免费额度、限流、前置条件（要不要实名、要不要绑账号）
4. **标验证日期**——政策会变，日期就是这条信息新鲜度的凭据

宁可只有五条，也不要三十条里混着付费和错误。
