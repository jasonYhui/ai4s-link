## 收录标准

一条资源能进这个库，需要满足：

1. **有官方出处**——能指到官网页面或官方公告，不是二手转述
2. **写清限制**——免费额度、有效期、前置条件（要不要实名、要不要绑账号）
3. **标验证日期**——政策会变，日期就是"这条信息新鲜度"的凭据

不满足就不要收。宁可只有四条，也不要三十条里有十条是错的。
