# 科研资源

这里是「科研羊毛」资源库，收录可申请的免费或低成本科研计算资源、数据资源与工具。
每条资源都按 **是什么 / 怎么用 / 免费额度 / 验证日期** 四段式整理，方便快速判断是否值得申请。

## 计算资源

- [CARSI 超算资源](./carsi-supercomputing) —— 中国学术互联网联盟的超算网络，可通过所在高校节点申请免费核时

## 说明

- 资源政策会变化，请以「验证日期」为准，并优先查阅官方页面
- 欢迎通过 GitHub Issue / Pull Request 补充新资源

## 新增一条资源的格式

```md
## 是什么
一句话说明这个资源是什么、由谁提供。

## 怎么用
1. 第一步…
2. 第二步…

## 免费额度
具体额度与限制条件。

## 验证日期
YYYY年MM月
```
