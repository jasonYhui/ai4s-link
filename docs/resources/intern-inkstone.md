# 书生·端砚 Intern InkStone

## 是什么

上海人工智能实验室的 AI 科研工作台，网页端与客户端都能用。官方帮助中心列出的能力包括：科研问答与深度研究、论文工具、课题空间、科学工具 / 科学数据 / 科学计算，以及可挂载数据集的开发机。

平台内的额度单位叫「**墨点**」，是 Token 的计量单位。

## 怎么用

1. 打开 <https://discovery.intern-ai.org.cn>
2. 微信扫码或第三方账号登录，注册即用，不需要申请
3. 网页端直接用；要用本地算力就下载客户端
4. 帮助中心：<https://discovery.intern-ai.org.cn/docs/>

## 免费额度

- 注册免费使用，**每月赠送 10,000 墨点**
- 墨点是平台内 Token 的计量单位，实际可用量取决于所选模型的倍率
- 另有 5 小时 / 7 天两个时间窗的使用限额
- 官网与官方文档未公开固定额度数字，实际到账以控制台显示的墨点余额为准

## 适合场景

- 整篇论文精读，并把结论沉淀成结构化笔记
- 跨学科问题检索（官方称可读懂生命科学、地球科学、物质科学等学科专业知识）
- 把一次对话「添加到课题」，攒成自己的课题资料库
- 本地没有 GPU 时，用它的开发机把流程跑通

## 验证日期

2026-11-23（平台与功能依据官方文档与官网；额度数值以控制台实际到账为准）
