# 魔搭社区免费算力

## 是什么

阿里巴巴的模型与数据集社区 ModelScope，除模型托管外还提供在线算力。官方首页写明：**CPU 资源长期免费，GPU 算力限额免费**。

## 怎么用

1. 注册 <https://www.modelscope.cn>
2. 按首页提示注册社区并绑定阿里云账号（领免费算力的前置条件）
3. 进入「云上算力」创建实例，按需选 CPU 或 GPU

不用在自己机器上装环境。

## 免费额度

- **CPU 资源：长期免费**
- **GPU 算力：限额免费**，需注册社区并绑定阿里云账号
- 具体 GPU 小时数以控制台显示的额度为准，官方首页未给固定数值

- 跑通一个 demo、验证想法，不值得为此买卡
- 加载开源模型做推理测试
- 教学演示、学生作业
