# CARSI 超算资源

::: info 基本信息
**全称**：中国学术互联网联盟（China Academic Supercomputing Interconnection）  
**官网**：[www.carsi.cn](https://www.carsi.cn)  
**申请方式**：通过所在高校或科研机构的 CARSI 节点统一申请  
**免费额度**：视各节点政策而定，通常提供数百核时的免费计算资源
:::

## 是什么

CARSI 是一个面向学术科研的分布式超算网络，连接了全国多所高校和科研机构的超级计算中心，为科研人员提供统一的计算资源调度服务。

## 怎么用

1. 确认你所在的机构是否接入了 CARSI
2. 联系所在机构的超级计算中心或信息化部门
3. 提交项目申请，说明研究内容和所需算力
4. 审核通过后获得计算账号和配额

## 免费额度

不同节点的免费政策差异较大，典型情况：
- 部分高校提供数百至数千核时的免费额度
- 某些节点对特定研究领域有额外补贴
- 具体额度需咨询所在机构的超级计算中心
